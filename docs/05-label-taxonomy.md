# Taxonomia de Labels

A taxonomia ainda é provisória e deverá ser validada com exemplos reais.

## Nível 1 — Spam

- `spam`
- `not_spam`

## Nível 2 — Categoria

Categorias iniciais candidatas:

- Financeiro
- Suporte
- RH
- Sistemas
- Comercial
- Administrativo
- Notificações
- Pessoal
- Outros

## Regra

Uma categoria só deverá permanecer no modelo se houver exemplos suficientes e se ela representar uma distinção útil para o usuário.

Categorias excessivamente parecidas podem ser consolidadas com base na matriz de confusão.
