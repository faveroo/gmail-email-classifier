# Escopo

## Dentro do escopo inicial

- classificação binária de spam;
- categorização temática de e-mails legítimos;
- treinamento supervisionado;
- dataset rotulado;
- cálculo de confiança/probabilidade;
- avaliação por métricas adequadas;
- integração futura com Gmail API;
- aplicação de labels de teste;
- fluxo de revisão humana.

## Fora do escopo inicial

- responder e-mails automaticamente;
- excluir mensagens automaticamente;
- treinar modelos generativos;
- usar LLMs como requisito para classificação;
- analisar anexos complexos;
- realizar ações irreversíveis no Gmail;
- treinamento contínuo totalmente automático sem validação.

## Possíveis extensões

- priorização de mensagens;
- detecção de phishing;
- classificação por remetente/departamento;
- dashboard de métricas;
- active learning;
- retreinamento assistido;
- comparação com Transformers;
- API própria para inferência.
